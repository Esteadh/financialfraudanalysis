# Financial Fraud Analysis
In this study, financial fraud risks were identified based on transaction times. Excel, Power BI, and MSSQL were used to conduct this analysis.
![MSSQL](https://img.shields.io/badge/Database-MS_SQL_Server-red.svg) ![Excel](https://img.shields.io/badge/Microsoft_Excel-217346?style=flat&logo=microsoft-excel&logoColor=white)  ![Power BI](https://img.shields.io/badge/Power_BI-F2C94C?style=flat&logo=power-bi&logoColor=black) 

# Project Summary 
The 280,000-row dataset obtained from Kaggle was cleaned as needed and prepared for SQL queries. Using SQL, analyses such as IQR analysis, outlier analysis, distribution analysis, and correlation analysis were performed, and the necessary visualizations were created in Power BI
